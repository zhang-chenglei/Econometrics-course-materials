# 第11—14章人工智能试验区综合案例复现包

## 材料性质

本包使用“真实政策背景＋半合成企业教学样本”。政策批复时间和试验区背景用于训练研究设计；企业面板经过抽样、清理和教学化处理。所有回归系数、显著性、异质性和机制模式只用于课堂演示，不能作为对真实政策效果的经验判断，也不能据此提出实际政策建议。

## 文件结构

- `第11章`：政策事实、处理批次、样本覆盖、研究设计验收和识别威胁地图；
- `第12章`：样本筛选、缺失检查、描述性统计、平衡性、分布和原始趋势；
- `第13章`：TWFE教学基准、交错DID、动态效应、稳健性、影响力、异质性和机制相关结果；
- `第14章`：最终论文式表图、关键数字一致性检查和完整教学报告；
- `共享代码/common.py`：数据读取、统一估计、交错DID聚合和图表样式；
- `共享代码/run_all.py`：按章节一次重新生成全部Python结果。

每章都按 `代码 / 表格 / 图形 / 说明` 分开保存。Python脚本是正式计算入口，CSV是机器可读结果，Markdown表便于教材引用，PNG是可直接插入文稿的图形。

## 运行顺序

推荐使用 Python 3.11—3.13，并先安装 `共享代码/requirements.txt` 中的依赖。完整复现可以运行：

```bash
cd materials/code/comprehensive_case
python 共享代码/run_all.py
```

也可依次打开各章 `代码/第XX章_可执行复现.ipynb`。笔记本按 `Goal—Setup—Steps—Checks—Next Steps` 组织，并在执行后保存关键表图的内嵌预览。

macOS上如果数值库初始化缓慢，可在运行前限制并行线程：

```bash
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export VECLIB_MAXIMUM_THREADS=1
```

## Python与Stata的关系

本次交付的数字和图形由Python代码实际生成并完成了从头运行检查。各章同时提供 `.do` 文件，方便使用Stata授课时对照实现。当前环境没有Stata可执行程序，因此 `.do` 文件经过静态检查但没有在本机实际运行；首次课堂使用前应在持有许可的Stata环境中运行，并记录版本与扩展包版本。

Stata脚本需要 `reghdfe`、`ftools`、`estout`、`coefplot`、`csdid` 和 `drdid`，脚本会在缺失时尝试从SSC安装。不同版本的 `csdid` 聚合选项可能略有差异，应以授课电脑上的帮助文件为准。

运行Stata版本前，请先将工作目录切换到仓库的 `materials` 文件夹。脚本会据此定位 `data/semisynthetic/` 中的教学样本和 `code/comprehensive_case/` 中的输出目录。

## 主要口径

- 面板期：2011—2024年；
- 处理起点：试验区正式批复后的第一个完整年度；
- 主结果：研发投入强度、`ln(1+发明专利申请数)`；
- 主估计：以从未处理企业为对照的组别—时期ATT及处理组规模加权聚合；
- TWFE：仅作教学基准；
- 推断：城市层面聚类标准误；
- 基准事件期：处理前一年；
- 教学代理变量：同期政策、办公地址和同省近邻代理只用于演示检验思路，不是真实测量。

## 结果使用规范

引用结果时优先使用第14章的最终表和 `表14-6_全文关键数字一致性检查`。任何数据更新都必须从第11章开始重新运行，不能只改表中的数字。正文应明确报告：数据的半合成性质、处理定义、对照组、估计量、置信区间、聚类层级、平行趋势联合检验、敏感规格和无法排除的识别威胁。

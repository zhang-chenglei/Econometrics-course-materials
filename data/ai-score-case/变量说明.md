# 第4讲 Agent Lab：变量说明

这是一份用于“从相关到因果”教学的**合成学生数据**，共 800 个观测。数据不对应任何真实学校或学生，不可用于评价现实中的 AI 教学效果。

| 变量 | 含义 | 时序与研究角色提示 |
|---|---|---|
| `student_id` | 匿名学生编号 | 仅用于识别观测 |
| `final_score` | 期末成绩（0—100） | 结果变量 $Y$ |
| `ai_hours` | 每周生成式 AI 学习使用小时数 | 核心解释变量/连续处理 $X$ |
| `prior_score` | 课程开始前基础成绩（0—100） | 处理前变量 |
| `motivation` | 学期开始时学习动机（1—10） | 处理前变量 |
| `digital_skill` | 学期开始时数字工具能力（1—10） | 处理前变量 |
| `study_hours` | 学期开始时每周自主学习小时数 | 处理前变量 |
| `assignment_quality` | 学期中的作业质量（0—100） | 学习过程变量，可用于讨论 AI 可能通过什么渠道影响成绩 |
| `gender` | 性别（0=男，1=女） | 处理前变量 |
| `class_id` | 班级编号（1—20） | 班级环境标识 |

## 重要边界

- 数据生成时保留了一个学生看不到的共同原因，使 `ai_hours` 与成绩误差项仍可能相关；因此即使加入全部可观察控制变量，也不能把系数自动解释为因果效应。
- `assignment_quality` 在学习过程中测量。它更适合帮助思考“AI 可能怎样影响成绩”，不应因为数据里有这个变量就机械地加入所有回归。
- 完整数据生成逻辑和固定随机种子记录在课程网站仓库的 `tools/generate_ai_score_case.py` 中；学生应先独立完成案例，再查看“代码和结果分析”页。

# 国家新一代人工智能创新发展试验区政策数据

本目录用于第11—15章贯穿案例的政策匹配。政策对象仅为科技部“国家新一代人工智能创新发展试验区”，不包含工信部“国家人工智能创新应用先导区”。

## 文件

- `ai_pilot_approvals.csv`：18个试验区正式批复的横截面主表；
- `ai_pilot_match_aliases.csv`：城市名称、直辖市代码和德清特殊规则；
- `ai_pilot_city_year_2010_2025.csv`：18个试验区地区2010—2025年年度面板；
- `build_city_year.py`：从批复表重新生成任意年份范围的政策面板；
- `变量说明.md`：字段定义和匹配规则；
- `政策来源.md`：国家文件、18份正式批复和完整性核验；
- `DID研究设计说明.md`：识别策略、风险和稳健性建议。

## 核心事实

- 首个正式批复：北京，2019年2月20日；
- 最后一组正式批复：沈阳、哈尔滨、郑州，2021年11月13日；
- 正式批复地区数：18；
- 相同批复日期组数：8；
- 唯一县级试验区：浙江省湖州市德清县。

## 生成城市年度表

```bash
python3 build_city_year.py
```

自定义年份：

```bash
python3 build_city_year.py --start-year 2012 --end-year 2024 \
  --output ai_pilot_city_year_2012_2024.csv
```

## 合并原则

1. 先用行政区划代码匹配，再用标准化中文名称复核。
2. 企业地址应固定在政策前，避免政策后迁址改变处理状态。
3. 与全国企业数据合并后，未匹配到18个试验区的企业设为从未处理。
4. 德清必须使用县级地址，不能用湖州市整体替代。
5. 年度结果变量的主设定建议从批复后的第一个完整年度开始。

## 数据边界

本目录只包含政府政策事实、公开链接和由这些事实生成的政策编码，不包含任何上市公司数据。`cohort_id`、`first_full_year`、`post` 和事件时间变量是为教学研究构造的分析字段，不是政府文件中的官方变量。

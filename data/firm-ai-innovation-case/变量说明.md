# 第4讲 Agent Lab：变量说明

这是一份用于“从相关到因果”教学的**合成企业横截面数据**，共 800 个观测。数据不对应任何现实企业，不可用于评价现实中 AI 对企业创新的影响。

| 变量 | 含义 | 研究角色提示 |
|---|---|---|
| `firm_id` | 匿名企业编号 | 仅用于识别观测 |
| `innovation_score` | 当期企业创新产出得分（0—100） | 结果变量 $Y$ |
| `ai_intensity` | 企业 AI 使用强度（0—10） | 核心解释变量/连续处理 $X$ |
| `prior_innovation` | 上一期创新产出得分（0—100） | 企业创新基础 |
| `rd_intensity` | 研发支出占营业收入比重（%） | 研发投入特征 |
| `digital_capability` | 数字化能力得分（1—10） | 企业能力特征 |
| `ln_employment` | 企业员工数的自然对数 | 企业规模特征 |
| `firm_age` | 企业成立年限 | 企业年龄特征 |
| `export_share` | 出口收入占比（0—1） | 对外开放特征 |
| `industry` | 行业编号（1—6） | 行业环境标识 |

## 重要边界

- 数据生成时保留了学生看不到的企业管理质量和市场机会因素。它们同时影响 AI 使用与创新产出，因此即使加入全部可观察企业特征，也不能把 AI 系数自动解释为因果效应。
- 创新能力强的企业也可能更愿意采用 AI，现有横截面数据不能单独排除这种反向关系。
- 完整数据生成逻辑和固定随机种子记录在课程网站仓库的 `tools/generate_firm_ai_innovation_case.py` 中。学生应先独立完成案例，再查看“代码和结果分析”页。

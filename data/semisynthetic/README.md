# 人工智能试验区半合成教学样本

## 重要声明

本数据仅用于第11—15章贯穿案例的计量经济学方法教学。企业—年份结构、城市、政策批次和部分协变量来自清理后的教学底板，但研发、专利和机制结果变量按照公开的数据生成过程重新生成，并植入了已知政策效应。因此，本数据不能用于判断国家新一代人工智能创新发展试验区的真实政策效果，也不能作为论文或政策报告中的现实证据。

## 样本

- 样本期：2011—2024年；
- 企业数：1,389家；
- 企业—年份观测：15,863个；
- 抽样方法：按试点编号和对照组分层，在企业层面随机抽取约50%；
- 抽样种子：20260720；
- 半合成种子：20260721。

## 清理规则

1. 从企业控制变量完整的教学样本出发；
2. 企业规模、资产负债率、ROA、成长性、有形资产比重和现金流按年度1%—99%缩尾；
3. ROA、成长性和现金流允许为负，因为负值具有真实经济含义；
4. 政府补助和研发人员重新生成并限制为非负；
5. 汕头2014年GDP增速109修正为10.9，深圳2022年330修正为3.3；
6. 城市变量先在城市内插值，再以年度中位数补齐；
7. 所有企业重新匿名编号，样本内不保留股票代码和公司名称。

## 半合成结果变量

研发投入强度和发明专利申请均保留企业政策前基线、共同年份变化、城市—年份冲击和随机扰动。政策前不加入处理效应；政策后从首个完整处理年度开始加入递增效应。技术相关行业的政策效应略高，用于演示异质性分析。

政府补助被设定为显著渠道；KZ和SA融资约束未植入政策效应；研发人员只植入较弱效应。这样可以演示“部分机制得到支持、部分机制不显著”的规范写法。

## 推荐主变量

- 研发结果：`rd_intensity_w`
- 专利结果：`ln_patent_invention`
- 主处理：`did_post_full`
- 交错DID处理年度：`gvar`
- 城市聚类：`analysis_city_id`
- 企业编号：`firm_id`

## 教学表述

课堂和教材中应始终使用“半合成教学数据”“预设数据生成过程”“已知政策效应”等表述。可以用它检验代码是否正确、比较估计方法和训练结果写作，但不能把估计数值解释为真实政策效果。

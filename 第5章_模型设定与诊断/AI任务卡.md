# 第5章 Agent任务卡：一份成绩回归的完整诊断

## 目标

用一张诊断清单区分函数形式、遗漏变量、多重共线性和异方差分别伤害什么，并对应到“改设定 / 改标准误 / 改识别策略”三类处理。

## 工作顺序

1. 只读检查数据生成过程中预设的几类问题。
2. 经确认后比较遗漏与控制`ability`的模型，并用 FWL 三步核对系数是否完全相等。
3. 计算VIF、运行 RESET 检验、检查残差。
4. 运行异方差检验，比较常规标准误与HC1稳健标准误。
5. 整理“问题—主要伤害什么—怎么发现—怎么处理”四列诊断清单。
6. 将实际输出、处理选择和未解决问题记录到`ai_log.md`。

## 必须核验

- FWL 第 3 步的斜率与多元回归系数完全相等，且残差回归不加常数项；
- 多重共线性主要影响单个系数的精度，不能机械按阈值删变量；
- RESET 检验显著指向**改设定**，不是换标准误；
- 异方差主要使常规标准误失效，稳健标准误不改变系数；
- 稳健标准误不能修复遗漏变量偏误，那属于外生性问题。

## 1. 第 1 步：先看数据（约 3 分钟）

### 你要做

```bash
python3 完整代码.py --step data
```

### 你会看到

`data/` 下三份 CSV：

- `dml_linear.csv`：线性情景
- `dml_nonlinear.csv`：非线性情景
- `causal_forest_trial.csv`：因果森林数据

### 怎么读

**DML 两份数据**：

- `digitalization_D`：数字化程度（核心解释变量）
- `productivity_Y`：劳动生产率（结果变量）
- `x1, x2, x3`：三个背景特征（控制变量）
- `true_effect`：真值 **2**（模拟设定）

**因果森林数据**：

- `large`：是否大企业
- `high_rd`：是否高研发
- `trial_W`：是否参加试点（随机分配）
- `productivity_Y`：生产率
- `true_CATE`：理论处理效应（1 或 5）

四类企业的理论均值是：

| 企业类型 | 未参加 | 参加 | 理论效应 |
|---|---:|---:|---:|
| 小企业、低研发 | 10 | 11 | 1 |
| 小企业、高研发 | 10 | 15 | 5 |
| 大企业、低研发 | 20 | 21 | 1 |
| 大企业、高研发 | 20 | 25 | 5 |

### 别误会

- 这些是**模拟设定**，不是论文估计结果。
- `trial_W` 是随机试点，所以处理组和对照组在模拟设计下天然可比；真实观察数据不能直接照搬。

## 2. 第 2 步：DML——平均效应（约 5—6 分钟）

### 你要做

```bash
python3 完整代码.py --step dml
```

约 **2.5 分钟**。第一次运行会生成下面两张图；如果时间紧，可以先看第 7 节的结果速查。

### 你会看到两张图

- `outputs/dml_density_comparison.png`：**密度分布图**
- `outputs/dml_three_line_table.png`：**规范化三线表**

这次只看这两张；其他 CSV/中间结果不用管。

### 先看三线表（非线性情景，真值 = 2）

| 方法 | 系数估计 | 95% 置信区间 |
|---|---:|---:|
| OLS（线性设定） | 2.605 | [2.559, 2.651] |
| OLS（正确设定：加 x1²、sin(2x2)） | 1.984 | [1.939, 2.029] |
| DML-Lasso（线性） | 2.607 | [2.562, 2.653] |
| DML-随机森林 | 2.033 | [1.979, 2.087] |
| DML-梯度提升树 | 2.012 | [1.966, 2.058] |
| DML-神经网络 | 1.982 | [1.934, 2.030] |

### 再看密度图

**左图（线性情景）**：3 条线——OLS 线性、DML-Lasso、DML-随机森林，都集中在 2.0 附近。  
左图右下角有小字说明：线性情景下 OLS 线性设定**本身已经正确**，所以不重复画“OLS 正确设定”；“OLS 正确设定”和 GBM/NN 只在右图出现。

**右图（非线性情景）**：6 条线——

- **OLS 线性**、**DML-Lasso** 在 **2.6** 附近；
- **OLS 正确设定**、**DML-随机森林**、**DML-梯度提升树**、**DML-神经网络** 在 **2.0** 附近。

### 你发现了什么

1. **线性情景**：OLS 线性设定已经正确，所有方法都接近 2.0。
2. **非线性情景**：OLS 线性 **2.605**；DML-Lasso **2.607**。两者都偏高，因为线性学习器学不到 `x1²` 和 `sin(2x2)`。
3. **OLS 正确设定 1.984**：如果研究者知道真实函数形式，把 `x1²`、`sin(2x2)` 显式加进 OLS，OLS 也能估对。
4. **DML-随机森林 2.033、梯度提升 2.012、神经网络 1.982**：灵活学习器能捕捉非线性背景关系，DML 把效应拉回 2 附近。
5. 所以：**DML 不是自动更好**；用线性学习器的 DML 也会像线性 OLS 一样失败。
6. **覆盖率**（50 次重复）：线性各方法约 **0.90—0.92**；非线性 OLS 正确约 **0.92**，DML-神经网络约 **0.78**、随机森林约 **0.48**、梯度提升约 **0.42**，OLS 线性和 DML-Lasso 约 **0.00**。**点估计准 ≠ 区间可靠**。

### 别误会

- 覆盖率是**模拟评价量**；这次 50 次的结果不等于 PPT 的 79%，也不是论文结论。
- 这不是原 PPT 120 次模拟的严格复现。
- DML 解决的是“控制关系形式复杂”的问题，不是所有内生性。

### 你可以这样问 AI 助手

> 请只展示 `outputs/dml_density_comparison.png` 和 `outputs/dml_three_line_table.png`，不要展示其他 CSV。用两分钟解释：为什么 OLS 线性和 DML-Lasso 都在 2.6，而 OLS 正确设定和随机森林/梯度提升/神经网络在 2.0。

## 3. 第 3 步：因果森林——谁受益更多（约 6—7 分钟）

### 你要做

```bash
python3 完整代码.py --step forest
```

约 **5 秒**。

### 你会看到两张图

- `outputs/森林_后续/forest_demo.png`：**因果森林直观图**
- `outputs/森林_后续/forest_three_line_table.png`：**规范化三线表**

### 先看直观图

**左图：四组估计 vs 理论**

- 横轴：小企业/大企业 × 低研发/高研发
- 柱子：评估样本上的估计效应；黑线：95% 置信区间；黑菱形：理论值 1 或 5
- 标题里有一句关键信息：**第一刀 60/60 棵树都选了高研发**

你会看到：低研发两组在 **1** 附近，高研发两组在 **5** 附近；柱子基本盖住黑菱形。

**右图：独立评估样本的高/低预测 CATE 组**

- 低预测组约 **1.60**，高预测组约 **4.51**
- 高减低 = **2.90**，p ≈ **7.5e-08**

### 再看三线表

| 组别 | 估计效应 | 95% 置信区间 | 理论值/说明 |
|---|---:|---:|---:|
| 小企业、低研发 | 1.070 | [0.656, 1.483] | 1 |
| 小企业、高研发 | 4.993 | [4.620, 5.366] | 5 |
| 大企业、低研发 | 1.081 | [0.679, 1.483] | 1 |
| 大企业、高研发 | 5.102 | [4.723, 5.480] | 5 |
| 低预测 CATE 组 | 1.603 | [0.844, 2.363] | — |
| 高预测 CATE 组 | 4.507 | [3.771, 5.243] | — |
| 高减低 | 2.903 | se = 0.540 | p = 7.5e-08 |

### 你发现了什么

1. 森林抓到了“**研发决定效应**”这个结构：低研发≈1，高研发≈5；规模主要决定水平，不决定效应。
2. 四组估计接近理论值 **1/5/1/5**。
3. 第一刀 **60/60** 棵树都按高研发切，和上面的四组结果一致。
4. 在**没参加森林训练**的评估样本里，高预测 CATE 组比低预测组高 **2.90**，p 远小于 0.05。
5. 森林输出的是 **CATE（条件平均处理效应）**：给定特征的企业平均会怎样，不是每家企业的真实个体处理效应。

### 别误会

- CATE 预测 **不是** 企业真实个体处理效应（ITE）。
- 这里的森林是**教学版诚实树集成**，用于解释思想，不是官方 GRF/EconML，不能作为论文方法引用。
- 四组估计接近 1/5/1/5，是因为数据是随机试点、按理论值生成的；真实观察数据不会这么干净，需要识别假设和混杂调整。
- 高 CATE 不等于“最应该扶持”；还要看成本、覆盖人群和政策目标。

### 你可以这样问 AI 助手

> 请运行 `--step forest`，展示 `outputs/森林_后续/forest_demo.png` 和 `forest_three_line_table.png`。解释左图四组为什么在 1 和 5 附近，右图高低预测组为什么能说明异质性，并说明 CATE 不等于个体真实效应。

## 4. 第 4 步：把 DML 和因果森林连起来（约 3 分钟）

| | DML | 因果森林 |
|---|---|---|
| 主要关心 | 平均效应有多大？ | 谁受益更多？ |
| 结果形式 | 系数、标准误、置信区间 | 四组估计、CATE、高低组差异 |
| 共同要求 | 可信的因果识别 | 可信的因果识别 |
| 不能做什么 | 不能自动消除内生性 | 不能把 CATE 当成个体真实效应 |

一句话：

> DML 帮你估“平均有多大”，因果森林帮你看“对谁更大”；两者都不能代替因果识别。

## 5. 第 5 步：讨论题（先自己想，再和同学讨论）

### 问题 1

把 `x1²` 和 `sin(2x2)` 也加入 OLS，会发生什么？

**提示**：OLS 也能接近 2。说明 DML 的优势来自“用机器学习灵活估计控制关系”，不是魔法；如果研究者已经知道正确的函数形式，OLS 也可以很好。

### 问题 2

DML-Lasso 为什么也在 2.6？

**提示**：DML 只是估计框架，辅助学习器是 Lasso（线性）；线性学习器学不到非线性背景关系。**DML 不是自动更好，学习器很关键。**

### 问题 3

CATE 预测很分散，是否一定存在真实异质性？

**提示**：不一定。有限样本噪声也会让预测值分散；要用独立评估样本检验高、低组的效应差异，不能只看 CATE 分布的宽度。

### 问题 4

为什么一定要独立评估样本？

**提示**：同一批数据既用来选分组、又用来估组效应，容易挑到噪声；诚实估计和样本外检验把“选分组”和“估效应/检验”分开。

## 6. 常见问题

| 情况 | 怎么办 |
|---|---|
| 提示缺 Python 包 | `python -m pip install -r requirements.txt` |
| 图形不弹窗 | 代码只保存 PNG，不弹窗；直接打开 `outputs/` 里的图片 |
| DML 跑得慢 | 约 2.5 分钟（GBM/NN 各 50 次）；第一次运行会生成 `outputs/` 里的图，之后直接打开即可 |
| 想多跑几次 | `python3 完整代码.py --step dml --reps 100`，结果会更平滑，但更慢 |
| 想换森林种子 | `--seed_forest 20261114` 是默认值；换种子后四组估计会变，不是 bug |
| 现场程序失败 | 把报错发给你的 AI 助手；常见原因是缺包、没在项目文件夹里运行，或 Python 版本不对 |
| 输出在哪 | 运行后：DML 在 `outputs/` 两张图；森林在 `outputs/森林_后续/` 两张图；数据在 `data/` |
| 不想用 AI 助手 | 直接把指南里的命令复制到终端运行 |

## 8. 最后提醒

- 你看到的是**教学模拟**，不是论文原始数据；不要把这些数字写进论文当实证结果。
- **CATE ≠ ITE**：森林给的是“具有这类特征的企业平均会怎样”，不是某一家企业自身的真实处理效应。
- 教学版森林是“诚实树 + 多树平均”的简化算法，不是官方 GRF/EconML。
- 真实观察性数据不能直接照搬随机试点的均值差；要先论证识别条件、做混杂调整。

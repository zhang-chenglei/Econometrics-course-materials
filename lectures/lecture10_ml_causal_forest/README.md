# 第十讲：DML 与因果森林｜课堂演示包

> 版本：2026-11-10  
> 配套课件：《第十讲_机器学习在计量经济学中的应用_阅读版》75 页  
> 定位：**教学模拟**，不是论文原始数据，也不是赵晶等、周迪等论文的严格复现。

## 这个包是什么

用三份教学模拟数据，把课堂上的三步跑一遍：

1. **看数据**：DML 真值 2；四类企业理论效应 1/5/1/5。
2. **DML**：OLS 线性、OLS 正确设定，以及 Lasso、随机森林、梯度提升、神经网络四种 DML 学习器。
3. **因果森林**：四组估计 vs 理论，独立评估样本的高/低预测 CATE 组差异。

运行后会生成四张结果图：

- `outputs/dml_density_comparison.png`：DML 密度分布图
- `outputs/dml_three_line_table.png`：DML 规范化三线表
- `outputs/森林_后续/forest_demo.png`：因果森林直观图
- `outputs/森林_后续/forest_three_line_table.png`：因果森林规范化三线表

## 文件夹结构

```
lecture10_ml_causal_forest/
├── README.md              # 本文件：总览与快速开始
├── 项目指南.md            # 给你的 AI 助手的逐步骤操作指南（学生视角）
├── 完整代码.py            # 单文件完整代码，支持分步运行
├── requirements.txt       # Python 依赖
```

初始文件夹只有代码和文档，没有 `data/`、`outputs/`，也没有预生成结果；运行命令后自己生成。

## 快速开始

```bash
# 进入这个文件夹；如果你已经在这里，跳过这一行
cd "lecture10_ml_causal_forest"
python3 完整代码.py --step all
```

首次运行约 **2.5 分钟**（DML 50 次，右图另含 GBM/NN 各 50 次）。运行后会生成四张结果图：DML 两张、森林两张。

如果本机还没装依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python3 完整代码.py --step all
```

## 三步运行

```bash
python3 完整代码.py --step data     # 第1步：生成三份模拟数据，约 2 秒
python3 完整代码.py --step dml      # 第2步：OLS/DML，约 2.5 分钟
python3 完整代码.py --step forest   # 第3步：因果森林，约 5 秒
```

每一步都会把结果写入 `data/` 或 `outputs/`，不会删除已有结果。

### 第 2 步会看到什么

只展示两张图：

- `outputs/dml_three_line_table.png`：六行三线表（OLS 线性、OLS 正确、DML-Lasso、随机森林、梯度提升、神经网络）
- `outputs/dml_density_comparison.png`：左图线性情景 3 条线；右图非线性情景 6 条线

关键结论：线性情景三种方法（OLS 线性、DML-Lasso、DML-随机森林）都接近 2.0；非线性情景 OLS 线性和 DML-Lasso 在 2.6 附近，OLS 正确设定和随机森林/梯度提升/神经网络在 2.0 附近。**DML 不是自动更好，辅助学习器很关键；正确设定的 OLS 也能估对。**

### 第 3 步会看到什么

只展示两张图：

- `outputs/森林_后续/forest_demo.png`：左图四组估计 vs 理论值 1/5，标题标注“第一刀 60/60 棵树按高研发切”；右图独立评估样本的高/低预测 CATE 组
- `outputs/森林_后续/forest_three_line_table.png`：七行三线表（四组估计、GATES 高低组、高减低）

关键结论：低研发两组约 1，高研发两组约 5；高预测 CATE 组比低预测组高约 2.90，p≈7.5e-08。**CATE 是条件平均效应，不是个体真实处理效应。**

## 怎么和 AI 助手一起用

把整个文件夹和 `项目指南.md` 交给你的 AI 助手（Claude Code、Cursor、Codex、Windsurf、GitHub Copilot、通义灵码等都可以），对它说：

> 请读取 `项目指南.md`，按第 1—5 步执行；每一步只运行指南里的命令，不要修改随机种子；运行后先展示指定图片，再用“怎么读”向我解释。

如果它不能运行终端，就把指南里的命令复制到终端自己运行，再打开 `outputs/` 里的图片看。每一节都写了“你要做 / 你会看到 / 怎么读 / 别误会”。

## 重要提醒

- 所有数据都是**教学模拟**；四类企业 1/5/1/5 是模拟设定，不是论文估计结果。
- DML 真值是 2；非线性情景下，**OLS 线性与 DML-Lasso 约 2.6**，**OLS 正确设定与 DML-随机森林/梯度提升/神经网络约 2.0**。DML 不是自动更好，取决于辅助学习器。
- **正确设定的 OLS**（显式加入 `x1²`、`sin(2x2)`）也能估对；这是本演示特意加入的对照。
- 覆盖率是**模拟评价量**；本演示不承诺重现 PPT 第 39 页的 79%。
- 因果森林输出的是 **CATE（条件平均处理效应）**，不是企业真实个体处理效应（ITE）。
- `完整代码.py` 里的森林是**教学版诚实树集成**，用于解释思想，不是官方 GRF/EconML 实现，不能作为论文方法引用。
- 随机试点 `trial_W` 由模拟设计保证可比；真实观察性数据不能直接照搬组均值差。

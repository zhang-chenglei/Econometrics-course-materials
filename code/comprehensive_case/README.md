# 第12—15章人工智能试验区综合案例复现包

## 材料性质

本包使用“真实政策背景＋半合成企业教学样本”。政策批复时间和试验区背景用于训练研究设计；企业面板经过抽样、清理和教学化处理。所有回归系数、显著性、异质性和机制模式只用于课堂演示，不能作为对真实政策效果的经验判断，也不能据此提出实际政策建议。

## 文件结构

- `第12章`：政策事实、处理批次、样本覆盖、研究设计验收和识别威胁地图；
- `第13章`：样本筛选、缺失检查、描述性统计、平衡性、分布和原始趋势；
- `第14章`：TWFE教学基准、交错DID、动态效应、稳健性、影响力、异质性和机制相关结果；
- `第15章`：最终论文式表图、关键数字一致性检查和完整教学报告；
- `共享代码/common.py`：数据读取、统一估计、交错DID聚合和图表样式；
- `共享代码/run_all.py`：按章节一次重新生成全部Python结果。

每章都按 `代码 / 表格 / 图形 / 说明` 分开保存。Python脚本是正式计算入口，CSV是机器可读结果，Markdown表便于教材引用，PNG是可直接插入文稿的图形。

## 运行顺序

推荐使用 Python 3.11—3.13，并先安装 `共享代码/requirements.txt` 中的依赖。完整复现可以运行：

```bash
cd code/comprehensive_case
python 共享代码/run_all.py
```

**Python 脚本按自身位置定位数据与输出目录，不依赖当前工作目录；Stata 脚本依赖当前工作目录**，运行前须按下文切换到含 `code/` 的教材根目录。数据既可在教材根目录下的 `GitHub课程网站/materials/`，也可在学生包内与 `code/` 同级。

也可依次打开各章 `代码/第XX章_可执行复现.ipynb`。笔记本按 `Goal—Setup—Steps—Checks—Next Steps` 组织，并在执行后保存关键表图的内嵌预览。

macOS上如果数值库初始化缓慢，可在运行前限制并行线程：

```bash
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export VECLIB_MAXIMUM_THREADS=1
```

## Python与Stata的关系

本次交付的数字和图形由 **Python 代码实际生成，并完成了从头运行检查**。各章同时提供 `.do` 文件，方便使用 Stata 授课时对照实现。

**两套代码的验证程度不同，使用前请留意区分：**

- **Python 链**：第12—15章已从头运行，产出的表图即本包交付的成果；
- **Stata 链**：已完成变量名、处理批次、固定效应、聚类层级、扩展包调用与工作目录约定的**逐项核对**，但**尚未在具备许可与完整扩展包的环境中整链实跑**。首次授课前请按配套 README 的方式切换工作目录后完整执行一遍，并记录 Stata 版本与扩展包版本。

下方所列扩展包（`reghdfe`、`ftools`、`estout`、`coefplot`、`csdid`、`drdid`）应在授课机上预先安装；脚本也会在缺失时尝试从 SSC 安装。不同版本的 `csdid` 聚合选项可能略有差异，应以授课电脑上的帮助文件为准。

运行Stata版本前，请先将工作目录切换到含 `code/` 的教材根目录（仓库内为 `30_教学/09_计量教材/`；学生包内即包根目录）。脚本会据此定位 `data/semisynthetic/` 中的教学样本和 `code/comprehensive_case/` 中的输出目录。

## 主要口径

- 面板期：2011—2024年；
- 处理起点：试验区正式批复后的第一个完整年度；
- 主结果：研发投入强度、`ln(1+发明专利申请数)`；
- 主估计：以从未处理企业为对照的组别—时期ATT及处理组规模加权聚合；
- TWFE：仅作教学基准；
- 推断：城市层面聚类标准误；
- 基准事件期：处理前一年；
- 教学代理变量：同期政策、办公地址和同省近邻代理只用于演示检验思路，不是真实测量。

## 结果使用规范

引用结果时优先使用第15章的最终表和 `表15-6_全文关键数字一致性检查`。任何数据更新都必须从第12章开始重新运行，不能只改表中的数字。正文应明确报告：数据的半合成性质、处理定义、对照组、估计量、置信区间、聚类层级、平行趋势联合检验、敏感规格和无法排除的识别威胁。
